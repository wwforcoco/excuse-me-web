World Clock

This world clock displays the current time, date, and UTC offset for major cities across the Americas, Europe, Asia, and Oceania. All times update live every second using your browser's built-in Internationalization API.

How to Use

  1. Five cities are shown by default: New York, London, Tokyo, Karachi, and Sydney.
  2. Use the dropdown to add more cities from the list of 20 available time zones.
  3. Click Remove on any card to hide it from the display.
  4. All clocks update automatically every second.

Available Cities

  • Americas: New York, Chicago, Denver, Los Angeles, Toronto, Sao Paulo, Honolulu
  • Europe: London, Paris, Berlin, Moscow
  • Asia: Dubai, Karachi, Mumbai, Bangkok, Shanghai, Tokyo, Seoul
  • Oceania: Sydney, Auckland

Frequently Asked Questions

How does the world clock update in real time?

The world clock uses your browser's built-in Internationalization API (Intl.DateTimeFormat) with IANA time zone identifiers. It refreshes every second to show the current time, date, and UTC offset for each selected city.

Does the world clock account for daylight saving time?

Yes. The browser's time zone database automatically handles daylight saving time (DST) transitions. The displayed time and UTC offset adjust correctly for each region's DST rules.

How many time zones can I display at once?

You can display as many as you like from the 20 available cities. Start with the five default cities (New York, London, Tokyo, Karachi, Sydney) and add or remove others as needed.
