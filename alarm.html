Online Alarm Clock

This alarm clock runs entirely in your browser. Set as many alarms as you need with optional labels. When the system clock matches an alarm time, a repeating audio alert plays through your browser speakers.

How to Use

  1. Choose a time using the time picker and optionally add a label.
  2. Click Set Alarm to add it to the list.
  3. When the alarm triggers, it pulses red and plays a two-tone beep. Click Dismiss to silence it.
  4. Click Delete at any time to remove an alarm before it rings.

Features

  • Set unlimited alarms with custom labels
  • Visual ringing animation with pulsing red border
  • Two-tone audio alert using the Web Audio API
  • Dismiss and delete controls for each alarm
  • Current time display at the top

Frequently Asked Questions

Does the online alarm clock work if I close the browser?

No. The alarm runs inside your browser tab using JavaScript. If you close the tab or the browser, the alarm stops. Keep the tab open and your computer awake for the alarm to sound at the set time.

Can I set multiple alarms at once?

Yes. You can add as many alarms as you need. Each alarm has its own time, label, and delete button. All active alarms are checked every second against the current system time.

What sound does the alarm make?

The alarm uses the Web Audio API to generate a two-tone alternating beep pattern through your browser. No audio files are loaded externally. The sound plays until you click Dismiss.

Will the alarm work if my computer goes to sleep?

No. If your computer enters sleep mode, JavaScript timers are paused and the alarm will not sound. Adjust your system settings to prevent sleep while the alarm is active.
