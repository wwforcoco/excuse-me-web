FAQ

Questions, answered

Everything you need to know before your first trade. Still curious? Our team is on chat 24/7.

Is Zenith a real exchange?+
No — Zenith is a premium landing page template for crypto exchanges, built with pure CSS. It is not a financial product and does not facilitate real trading. Use it as a starting point for your own exchange marketing site.
Does the template use any images?+
No. Every visual — coin logos, candlestick charts, sparklines, avatars, the security shield and all icons — is crafted from pure CSS gradients, clip-paths and shapes. No <img> tags, no background-image URLs, no external assets beyond Google Fonts.
Is the staking calculator functional?+
Yes. The staking calculator runs entirely in the browser using vanilla JavaScript. Adjust the amount, APR and duration sliders and the estimated earnings update in real time using the formula: earnings = principal × (apr / 100) × (days / 365).
How do I customize the brand?+
All colors, fonts and spacing live in CSS custom properties at the top of the <style> block. Change --blue, --green and --purple to retheme the entire page instantly, and swap "Zenith" in the nav and footer for your own brand name.
Is it mobile responsive?+
Fully. The layout collapses cleanly at 1024px, 760px and 480px breakpoints. The trading dashboard stacks vertically on mobile, the nav collapses to a toggle, and all tap targets remain comfortable on touch screens.
Can I use this commercially?+
Yes. This template is free to use for personal and commercial projects. A credit link to ExcuseMeWeb in the footer is appreciated but not required. Cryptocurrency services shown are illustrative only.
How do I download the source?+
Click the floating "Download HTML" button in the bottom-right corner of the page. The complete, self-contained HTML file — including all CSS and JavaScript — will download as premium-crypto-landing-page.html.
