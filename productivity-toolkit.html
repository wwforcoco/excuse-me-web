Frequently Asked Questions

What is the pomodoro technique?

The pomodoro technique uses 25-minute focused work sessions followed by 5-minute breaks. After four sessions, take a longer 15-30 minute break. The timer in this toolkit follows the standard 25/5/30 cycle but you can customize it.

Where is my to-do list stored?

All tasks are saved in your browser's localStorage under a unique key. Nothing is sent to a server. If you clear browser data or use private/incognito mode, your tasks will be lost.

Can I use the planner on multiple devices?

The planner works offline on each device, but it does not sync automatically. To share between devices, save the page (Ctrl+S) and host the HTML file on a cloud drive like Dropbox or Google Drive.

Does the timer keep running when I close the tab?

No. The pomodoro timer runs only while the tab is open. If you need background timing, use a desktop timer app or browser extension that supports background tabs.
