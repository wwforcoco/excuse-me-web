Frequently Asked Questions

How many named colors does CSS support?

CSS supports 148 named colors, including 17 standard colors and 131 extended colors added in SVG and CSS3. This tool lists all of them.

Do all browsers support CSS named colors?

Yes, all 148 CSS named colors are supported in every modern browser (Chrome, Firefox, Safari, Edge) and even in older browsers going back many years. They are safe to use in production.

Can I use named colors in CSS?

Absolutely. You can use named colors anywhere you use color values in CSS: color, background-color, border-color, box-shadow, etc. Example: body { background-color: cornflowerblue; }
