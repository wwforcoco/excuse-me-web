Frequently Asked Questions

What are meta tags?

Meta tags are HTML elements that provide information about a web page to search engines and website visitors. They appear in the <head> section and include the title, description, keywords, and other metadata that help search engines understand and rank your page.

Why is there a 60 character limit for titles and 160 for descriptions?

Google typically displays the first 50-60 characters of a title tag and about 155-160 characters of a meta description in search results. Staying within these limits ensures your text isn't truncated with an ellipsis, keeping your full message visible to users.

What is the robots meta tag?

The robots meta tag tells search engine crawlers how to index and follow links on a page. Common values include 'index, follow' (default), 'noindex' (don't show in results), 'nofollow' (don't follow links), and combinations like 'noindex, nofollow'.

What is a canonical URL?

A canonical URL specifies the preferred version of a web page when multiple URLs have identical or similar content. It helps prevent duplicate content issues by telling search engines which URL should be considered the authoritative source.
